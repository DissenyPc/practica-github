## Documentación del Proyecto

### ¿Qué es GitHub y qué relación tiene con Git?
Git es el motor de control de versiones (la herramienta que instalamos en Debian), mientras que GitHub es la plataforma en la nube que aloja esos repositorios. Git funciona de forma local y GitHub permite la colaboración, el respaldo y la gestión visual (Issues, Pull Requests, etc.) de esos proyectos.

### Tipos de repositorios en GitHub
* **Públicos:** Cualquier persona en internet puede ver el código, aunque solo los colaboradores autorizados pueden modificarlo. Son la base del Open Source.
* **Privados:** Solo el propietario y los colaboradores invitados pueden ver y trabajar en el código. Son ideales para proyectos comerciales o tareas escolares personales.
